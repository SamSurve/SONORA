# 🎧 SONORA

**Your Music. Your Library. Your Control.**

SONORA is a self-hosted music downloader and personal media library built with Python and FastAPI. Download supported media, customize metadata, manage playlists, and organize your music in one place.

### ✨ Features
- 🎵 Multiple download profiles: FLAC, MP3, M4A & MP4
- 🖼️ Custom metadata and album artwork
- 📚 Persistent download history and library
- ⚡ Background jobs with live progress tracking
- 📦 Playlist downloads and ZIP packaging
- 🔐 Session isolation and security hardening
- 🐳 Docker support and automated testing

### 🛠️ Tech Stack
`Python` · `FastAPI` · `yt-dlp` · `FFmpeg` · `Mutagen` · `SQLite` · `JavaScript` · `Docker`

### 🚀 Project Status
**Active Development** — focused on reliability, security, and production readiness.
