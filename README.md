# 🎧 SONORA

### Your Music. Your Library. Your Control.

SONORA is a self-hosted music downloader and personal media library built with **Python and FastAPI**. Download, organize, customize, and manage your music — all in one place.

### ✨ Features
- 🎵 **Flexible Formats** — FLAC, MP3, M4A & MP4 profiles
- 🖼️ **Rich Metadata** — Edit track details and album artwork
- 📚 **Personal Library** — Persistent history and organized downloads
- ⚡ **Live Progress** — Background jobs with real-time updates
- 📦 **Playlist Packaging** — Bundle tracks into ZIP archives
- 🔐 **Security First** — Session isolation and safer request handling
- 🐳 **Deployment Ready** — Docker support and automated tests

### 🛠️ Built With
`Python` · `FastAPI` · `yt-dlp` · `FFmpeg` · `Mutagen` · `SQLite` · `JavaScript` · `Docker`

### 🚧 Status
**Actively Developed** — built with a focus on reliability, security, and maintainability.

### ⚖️ Disclaimer
Use SONORA only for media you own or are legally permitted to download. Respect copyright laws and platform terms.
